# Overview

My app allows for the utilization and adding of flash card sets. Each flash card set will have a list of flashcards that you can either delete or add to the list as a whole. You can further test your knowledge fo the flash card set as you normally would with flash cards. 

My purpose for writing this program was to help me cultivate and improve my skills in app development, specifically utilizing Android and Kotlin due to how prevalent they are in app development.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

The primary tool that I used to help build this software was Android Studio.
I used the assistance of ChatGPT to help understand some of the syntaxing of Kotlin and complexities of the Android Studio workings, especially with the very laggy error detections.

I used the programming language of Kotlin along with a custom class, KotlinSupport, that I put together as I learned Kotlin and put together the app. I also used the multitude of libraries that are required to build various aspects of an app due to the fact that few functions are inherent to Kotlin.
